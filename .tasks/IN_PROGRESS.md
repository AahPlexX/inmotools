    1. `559ea4c` — **CIF import silently returned only the asymmetric unit.** Real-world CIF files list unique atoms plus a `_space_group_symop_operation_xyz` (or legacy `_symmetry_equiv_pos_as_xyz`) loop; `structureFromCif` never applied it, so e.g. a standard NaCl CIF imported as 2 atoms instead of 8, corrupting every downstream calculation (formula, density, bonds, diffraction). Fixed by extracting `expandSitesBySymmetry` (shared with `generateEquivalentSites`) and a new `parseSymmetryOperationXyz` CIF/SHELX-triplet parser in `symmetry-engine.ts`, applied during CIF import in `cif-engine.ts`.     2. `57f04ac` — **Diffraction panel `useMemo` stale on site edits.** `CrystalDiffractionPanel.tsx`'s powder-pattern memo depended on `document.cell` only, but `|F|²`-weighted intensity also reads `document.sites`; editing an atom left the plot showing the previous structure. Fixed the dependency array.
    3. `57f04ac` — **Brillouin-zone SVG `key` collision.** `CrystalReciprocalPanel.tsx` keyed wireframe edges by `` `${index}-${face[0]}` ``, which collides across faces sharing an edge index and first-vertex index. Added `faceIndex` to the key.
    4. `d414ebe` — **Neutron-mode diffraction silently reused the X-ray amplitude model.** `structureFactor` always used atomic number Z regardless of radiation kind (master-design item 90 requires bundled coherent scattering-length data for neutron intensities); Z does not track neutron scattering length b (e.g. H is negative). Added `ElementReference.coherentScatteringLength` (fm, NIST NCNR-sourced) for all 20 bundled elements, an optional `radiation` param on `structureFactor`/`structureFactorIntensity` (default `'xray'`, all 6 existing call sites unaffected), wired through `simulatePowderPattern`'s existing `options.kind`. 3 new tests in `tests/unit/crystal-structure-factor.test.ts`. Known follow-up, not yet done: `single-crystal-engine.ts` (single-crystal + Laue) and the reflection-table export in `structure-export-engine.ts` still default to X-ray — no UI currently exposes a radiation choice on those paths, so this is a real but currently-unreachable gap, not a regression.

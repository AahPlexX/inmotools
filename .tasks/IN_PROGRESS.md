    1. `559ea4c` — **CIF import silently returned only the asymmetric unit.** Real-world CIF files list unique atoms plus a `_space_group_symop_operation_xyz` (or legacy `_symmetry_equiv_pos_as_xyz`) loop; `structureFromCif` never applied it, so e.g. a standard NaCl CIF imported as 2 atoms instead of 8, corrupting every downstream calculation (formula, density, bonds, diffraction). Fixed the dependency array.

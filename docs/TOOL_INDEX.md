# Tool index

One row per catalog tool, joined on the catalog slug. Start here, then follow the links. The rules for every column are in [DOCUMENTATION_STANDARD.md](DOCUMENTATION_STANDARD.md).

- **Spec:** the tool's design record today. `dedicated` = its own spec; `shared section` = one section of a multi-tool spec; `sub-feature only` = a spec covering part of the tool; `none` = no spec yet.
- **Tracker:** the standard `TRACKER.md`; `none` until the tool is standardized.
- **Other docs:** existing tracking files, kept as written and linked from the tracker.
- **Task:** where the tool's own entry is in `.tasks/` (`IN_PROGRESS`, `DONE`, `WORK_LOG only`, or `none`).
- **Standard:** `done` once the tool has a standard spec and tracker; `pending` until then; `deferred (active elsewhere)` while another workstream owns the tool.
- **Former names:** previous display names, so older records still match.

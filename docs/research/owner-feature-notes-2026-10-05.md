# Owner feature notes (spec input)

Owner's per-tool function lists, given 2026-10-05, kept as input for the tools' specs. They are not requirements by themselves. Rules for using them (docs/DECISIONS.md, 2026-10-04/05): the repository wins where they differ (existing code, tests, libraries, names, slugs, storage formats, earlier decisions); a function that fits the platform rules and is not built becomes a `missing` requirement; one that breaks a rule is `prohibited` with the reason; LLMs are prohibited, other ML is decided by the ML ruleset. Three tools in the notes are not in the catalog and are left out: Crafting Template Designer / inmo-craft, Guitar Fretboard & Pitch Tuner, Perspective Drawing Guide. Names such as `inmo-pdf` and the Dexie schemas in the notes are not used.

Known conflicts (checked 2026-10-05): "Bionic Reading" / bolding the first half of each word is a registered trademark with a stated patent (BRCG Casutt GmbH, USPTO 5557651) — prohibited; fetching arbitrary URLs through a "CORS proxy" needs a server — prohibited (direct requests to sites that allow CORS are fine); multi-threaded WebAssembly needs COOP/COEP headers, which GitHub Pages cannot send — single-threaded only; browsers coarsen timers, so "microsecond" / "nanosecond" / "sub-millisecond" precision is stated as millisecond precision; synthetic quiz generation from text would need an LLM — prohibited; Web Speech voices that send text to a server do not keep data on the device — on-device voices only; "LAME.js" / "WebAssembly LAME" are library names, the repository uses MediaBunny encoders.

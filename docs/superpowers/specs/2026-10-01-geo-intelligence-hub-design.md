# Geo Intelligence Hub — spec

As built at `94e112f2` (last change under `src/tools/geo-intel/`). Requirement prefix: `GIH`. Status of each requirement: [TRACKER.md](../../../src/tools/geo-intel/TRACKER.md).

## Purpose

Turn any place name, postal code, coordinate or grid reference into one location profile (country, admin areas, time zone, sun, elevation, holidays, population, regional statistics) in which every value names its source, year, license and precision. For travellers, researchers, GIS and data teams, and journalists.

## Scope

In scope:
- Lookups from keyless public sources that allow browser (CORS) requests from the GitHub Pages origin.
- Bundled offline data for country, time zone, populated places and admin-1 names.
- Coordinate and grid conversion, measurement, comparison, batch postal lookup, and exports.

Out of scope:
- Any source that needs an API key, account or signup: repository rule (no auth).
- Open Topo Data public API: sends no CORS header, so browsers block it.
- BigDataCloud for arbitrary coordinates: its free endpoint is limited to the device's own location.
- Bundled GISCO NUTS geometry: GISCO geodata terms are non-commercial; only the code-returning ID service is used.
- REST Countries live, Open-Meteo, IP geolocation: excluded in the original brief.
- Items listed as `not planned` in the requirements table (each breaks a source's terms or licence, or needs a key).

## Constraints

- Static GitHub Pages hosting; no server, no database, no user accounts.
- Local-first: history, saved profiles, tags, settings and the response cache stay in this browser (IndexedDB `inmotools-geo-intelligence-hub`).
- No new npm dependencies; only dependencies already pinned in `package.json` or in-house code checked against official test vectors.
- `src/tools/geo/` (GeoJSON Simplifier) is never touched.
- Static data is generated by `src/tools/geo-intel/scripts/build-data.mjs` and committed under `data/`; the site build needs no network.
- Sources and their licenses: the verified source registry in [TODO.md](../../../src/tools/geo-intel/TODO.md).
- A postal-code population is never fabricated; population is reported only for the geography that publishes it (country, NUTS region, populated place), with that geography and year.

## Definition of done

The tool is complete when every requirement is `verified` or `not planned`, and the completion gates in `.tasks/PROJECT_COMPLETION.md` are met.

## Intent not recorded

- PDF text is limited to WinAnsi (Helvetica), so non-Latin names are transliterated or dropped in the PDF only. Unknown: whether full Unicode in the PDF is required.
- Nominatim cannot be switched off remotely without a redeploy. Unknown: whether a remote kill switch is required.
